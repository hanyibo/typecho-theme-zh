# ZH · Typecho 简约单栏主题

**ZH 主题** —— 一款简洁、简介、精致的单栏 Typecho 博客主题。无冗余依赖、无外部 CDN，开箱即用。

- 演示站点：<https://www.hanyibo.com>

- **环境要求**：Typecho **1.3** / PHP **8.0+** / MySQL **8.0+**
- **功能**：左图右文卡片列表 · 深色模式（跟随系统 + 手动记忆）· 顶部站内搜索 · 图片灯箱 + 原生懒加载 · 代码高亮（内置 Prism，无 CDN）· 返回顶部 · 移动端菜单 · 嵌套评论 · 友情链接页 · 归档时间轴 · 页面缓存（四开关 + 智能失效）· 完整 SEO（TDK / Canonical / Open Graph / JSON-LD / robots）

## 安装

1. 将整个 `ZH` 文件夹拷贝到站点的 `usr/themes/` 目录下（确保路径为 `usr/themes/ZH/index.php`）；
2. 进入 Typecho 后台 → **控制台 → 外观**，启用「ZH · 简约单栏主题」；
3. 建议 Typecho 设置中开启**伪静态**（ rewriting ），搜索与标签链接体验更佳。

## 创建导航页面（重要）

导航栏的「分类 / 归档 / 关于 / 友情链接」由独立页面承载。首次使用请依次创建：

| 页面 | 标题随意 | 自定义模板 | slug（缩略名） |
|------|----------|-----------|----------------|
| 分类索引 | 分类 | **分类** | `categories` |
| 归档 | 归档 | **归档** | `archives` |
| 关于 | 关于 | 无（默认页面） | `about` |
| 友情链接（可选） | 友情链接 | **友情链接** | `links` |

创建页面时把「缩略名」设为上表 slug，主题会**自动识别**这些页面的真实链接填入导航（`links` 页面创建后导航自动出现「友链」入口）；如果你的 slug 不同，或想指向其他地址，在「外观设置」中修改对应链接即可。

## 外观设置

启用主题后进入 **控制台 → 外观 → 设置外观**：

| 设置项 | 说明 |
|--------|------|
| 默认缩略图地址 | 文章无图时的占位图，留空用主题内置 SVG；也是 og:image 兜底 |
| Favicon 图标地址 | 浏览器标签页图标，ico / png / svg 均可；留空则不输出，浏览器会尝试站点根目录的 /favicon.ico |
| 首页 SEO 描述 / 关键词 | 首页 meta 信息，留空则用 Typecho「站点描述」 |
| 归档 / 分类 / 关于 / 友链页链接 | 导航对应项的地址，页面 slug 规范时无需填写；「友链」在页面与设置均未提供时不显示导航入口 |
| 友情链接 | 每行一个：`名称\|链接\|描述`（描述可省略） |
| 额外导航项 | 追加到导航栏，每行一个：`名称\|链接` |
| ICP 备案号 / 页脚文案 | 展示在页脚 |
| 自定义 head / 页脚代码 | 放搜索引擎站点验证、统计代码等，无需改模板 |
| 首页 / 归档页 / 文章页 / 独立页缓存 | 页面缓存开关，均为独立控制，默认全部关闭 |
| 缓存有效期（秒） | 缓存文件的最长寿命，默认 3600，实际内容变更后会提前失效 |

## 页面缓存说明

主题内置零依赖的**文件级页面缓存**（参考 rizhi 主题思路并强化），可为访客缓存页面主体区域，显著降低数据库查询次数；评论区始终实时渲染，不受缓存影响。

- **四个独立开关**：首页 / 归档页（分类、标签、日期、搜索）/ 文章页 / 独立页（含归档、分类、友链自定义模板），均在「外观设置」中控制，默认关闭。
- **智能失效**：缓存命中时会校验内容指纹（文章篇数、任意文章/页面的修改时间、评论总数、分类/标签变动、相关主题设置）。后台发表/编辑/删除文章、评论增删与审核、修改外观设置后，下一次访问即自动重建缓存，**无需手动清理**（无需依赖 Typecho 编辑钩子，比传统主题缓存更可靠）。
- **安全边界**：登录用户跳过缓存（所见即所得）；非 GET 请求（提交评论等）不缓存；**密码保护的文章与独立页永不缓存、列表中出现受保护内容时该页本次不落盘**（渲染结果依赖访客密码 Cookie，落盘即等于公开）；缓存文件落在 `usr/cache/ZH-theme/`（自动创建，原子写入，并自动写入 `.htaccess` / 空 `index.html` 阻止 Web 直访）。
- **磁盘维护**：缓存写入时以低频触发垃圾回收，自动清理超过有效期的陈旧文件；搜索页等不可枚举 URL 不会无限累积。
- **手动清理**：紧急情况可直接删除 `usr/cache/ZH-theme/` 目录。若使用 nginx，建议在配置中拒绝该目录的直接访问：`location ^~ /usr/cache/ZH-theme/ { deny all; }`。

## 文章编辑页自定义字段

| 字段 | 说明 |
|------|------|
| `thumb` | 自定义缩略图，**优先级最高** |
| `description` | SEO 描述，留空自动截正文前 110 字 |
| `keywords` | SEO 关键词，留空自动用文章标签 |

**缩略图逻辑**：自定义字段 `thumb` → 正文第一张图片 → 文章附件图片 → 默认缩略图。

## SEO 说明

- 每页独立 `<title>`（翻页自动加「第 N 页」）与 `description`/`keywords`
- 每页输出 `rel="canonical"`；搜索结果页输出 `robots: noindex`
- 文章页输出 Open Graph / Twitter Card 与 JSON-LD `BlogPosting` 结构化数据，首页输出 `WebSite`（含站内搜索 Sitelinks 信息）
- 语义化 HTML5：每页唯一 `<h1>`、`<time datetime>`、图片 alt = 文章标题
- 保留 Typecho 原生 RSS 与评论反垃圾；代码高亮/JS 仅在需要时加载
- Sitemap 建议使用 Typecho 插件生成（主题不越权处理）

## 目录结构

```
ZH/
├── index.php            # 主题入口 + 首页列表
├── header.php           # SEO head + 导航栏
├── footer.php           # 页脚 + 脚本加载
├── post.php / page.php  # 文章页 / 独立页
├── archive.php          # 分类/标签/日期/搜索归档
├── comments.php         # 嵌套评论
├── categories.php       # 自定义模板「分类」
├── archives.php         # 自定义模板「归档」
├── links.php            # 自定义模板「友情链接」
├── 404.php
├── functions.php        # 主题设置与辅助函数（含页面缓存 zh_cache_*）
└── assets/
    ├── css/style.css    # 唯一样式表（明暗双色板）
    ├── js/main.js       # 交互脚本（无 jQuery）
    ├── img/default-thumb.svg
    └── vendor/prism/    # 本地 Prism 代码高亮
```

缓存文件生成于站点 `usr/cache/ZH-theme/`（运行时自动创建，不随主题分发）。

## 常见问题

- **搜索无效**：检查 Typecho「设置 → 永久链接」是否正常；未开启伪静态时搜索走默认路由，同样可用。
- **缩略图不显示**：外链图片可能有防盗链，建议图片上传到站内附件。
- **导航「分类」点击没反应**：确认已创建 slug 为 `categories` 的页面，或在外观设置里填写了分类页链接。
- **深色模式不生效**：主题优先读取手动选择，其次跟随系统；首次访问由系统偏好决定。
- **页面缓存不生效**：确认外观设置中对应开关已启用，且当前未登录（登录用户不走缓存）。
- **改了文章/评论但页面没更新**：检查缓存有效期是否设置过长（指纹校验应立即失效，如遇插件绕过 Typecho 接口写库则可能不触发）；可临时关闭再开启缓存开关强制重建。
